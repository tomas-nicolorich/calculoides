# Bug Report: Savings Goal Page Implementation Drift

**Status**: Patched
**Patched**: 2026-05-30
**Type**: Implementation drift
**Severity**: Medium
**Feature**: 003-project-redesign
**Reported**: 2026-05-30

## Description
The Savings Goal page (`SavingsPage.tsx`) does not adhere to the "sleek, colorful, and subtle" card-based design pattern established for the 003-project-redesign. While the dashboard and other main pages have been updated, the savings page still uses a standard grid/header layout without the specific card primitives and styling used elsewhere in the redesign.

## Artifact Traceability

### spec.md
- **Affected user story**: User Story 1 - Dashboard Overview (Priority: P1)
- **Affected requirements**: 
    - **FR-002**: System MUST provide a prominent button on the dashboard that navigates to the Savings Goal page.
- **Gap identified**: While the navigation was specified and fixed (BUG-004), the visual style of the target page was assumed to be either existing or handled independently, leading to a visual mismatch with the rest of the application.

### plan.md
- **Affected sections**: 
    - **Summary**: Mentions redesigning "dedicated sub-pages", but focus was primarily on Dashboard and Expenses.
    - **Scale/Scope**: Lists "~3 dedicated sub-pages", which likely included Expenses and Transfers, but Savings Goal page was missed in the redesign effort.
- **Impact**: The plan needs to explicitly include the redesign of the Savings Goal page to maintain visual consistency across the entire application.

### tasks.md
- **Affected tasks**: 
    - **T015b [US1]**: Add prominent "Savings Goal" navigation button to Dashboard. (Marked complete, but the target destination is unstyled).
- **False completions**: None, as the redesign of this specific page was not explicitly tasked.
- **Missing tasks**: 
    - [ ] Create redesign test for Savings Goal page in `frontend/tests/pages/savings.test.tsx`
    - [ ] Redesign Savings Goal page using `Card` primitives and Tailwind 4 color variables in `frontend/src/pages/savings/ui/SavingsPage.tsx`
    - [ ] Update Savings Goal widgets (List and Form) to match the new aesthetic.

## Root Cause Analysis
The redesign effort focused heavily on the core dashboard and the primary expense/transfer list pages. The Savings Goal page was treated as an existing utility page rather than a core component of the redesign scope, despite being accessible directly from the dashboard. This resulted in "implementation drift" where the newer code (Dashboard) points to older-styled UI components.

## Recommended Fix
1. Run `/speckit.bugfix.patch` to update `plan.md` and `tasks.md` to include the Savings Goal page redesign.
2. Run `/speckit.bugfix.verify` to confirm consistency.
3. Resume `/speckit.implement` to apply the visual updates to the savings page and its components.
