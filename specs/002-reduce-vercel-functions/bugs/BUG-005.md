## Description
During the login flow, the application throws an `Uncaught TypeError: Cannot read properties of undefined (reading 'name')` at `InvitationList.tsx:59:74`. This prevents the dashboard from rendering correctly. The error occurs when the `InvitationList` component attempts to map over an array of invitations and access the `group.name` property, but the `group` object is undefined.

## Root Cause Analysis
The consolidated Groups handler (`api/src/handlers/groups.ts`) likely defaults to returning a list of Groups when the action is not explicitly provided or when a `GET` request is made to `/api/invitations` without proper method-aware dispatching. The frontend expects an array of Invitation objects (which have a `group` property), but receives an array of Group objects (which do not have a `group` property), leading to the `TypeError` when accessing `invitation.group.name`.
