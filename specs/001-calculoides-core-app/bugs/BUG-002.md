# Bug Report: Supabase URL Missing in Frontend

**Type**: Dependency issue
**Severity**: Critical
**Feature**: 001-calculoides-core-app
**Reported**: 2026-05-14

**Status**: Patched
**Patched**: 2026-05-14

## Description
The application fails to load in the browser with the error `Uncaught Error: supabaseUrl is required`. This occurs because the Supabase client initialization in `AuthProvider.tsx` receives `undefined` for both `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`. Although these variables are present in the root `.env` file, they are not accessible to the Vite frontend because it expects them in `frontend/.env` or requires the Vite configuration to point to the root `.env`.

## Root Cause Analysis
The bug exists because of a mismatch between the directory structure (split monorepo) and the default environment variable loading behavior of Vite. Vite expects `.env` files in its project root (`frontend/`), while the project has a single `.env` at the system root. Additionally, the implementation tasks only accounted for the database connection string and not the client-side Supabase keys.
