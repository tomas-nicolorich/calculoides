# Bug Report: Owner Cannot Modify Member Incomes

**Type**: Spec gap
**Severity**: Medium
**Feature**: 001-calculoides-core-app
**Reported**: 2026-05-15
**Status**: Patched
**Patched**: 2026-05-15

## Description
The group owner is currently unable to modify the monthly income of other group members. While the specification allows members to set their own incomes (US1), it does not explicitly grant the owner the administrative privilege to adjust these values for the group, which is a requirement for group management.

## Artifact Traceability

### spec.md
- **Affected user story**: US1 — Group Setup & Income Distribution
- **Affected requirements**: FR-008 (Owner Permissions)
- **Gap identified**: FR-008 lists exclusive owner permissions (invite/remove, transfer budgets, archive) but omits the ability to modify member incomes.

### plan.md
- **Affected sections**: Technical Context -> Constraints
- **Impact**: RLS policies for the `group_members` table (or wherever income is stored) likely restrict updates to the authenticated user's own record. These policies need to be expanded to allow the group owner to update any member's record within their group.

### tasks.md
- **Affected tasks**: 
    - T015: Create GroupService for CRUD and member management in api/src/services/group.ts
    - T018: Create Group creation and Income setting features in frontend/src/features/groups/
- **False completions**: None.
- **Missing tasks**: 
    - [ ] Update RLS policies for `group_members` to allow owners to update `income` for all group members.
    - [ ] Update `GroupService` to allow owners to modify incomes of other members.
    - [ ] Update Frontend Income setting UI to allow owners to edit other members' values.

## Root Cause Analysis
This is a spec oversight. The original requirement focused on self-management of income (US1), and the expanded owner permissions in FR-008 missed this specific administrative capability.
