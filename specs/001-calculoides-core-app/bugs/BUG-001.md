# Bug Report: Empty App Shell - Missing Pages, Routing and Auth UI

**Type**: Spec gap
**Severity**: Critical
**Feature**: 001-calculoides-core-app
**Reported**: 2026-05-13
**Status**: Patched
**Patched**: 2026-05-13

## Description
Starting the local server results in a blank page showing only the word "Calculoides". The application lacks a login mechanism, navigation, and a dashboard view, despite these being required by the specification and several implementation tasks being marked as complete. The features exist as isolated components in `frontend/src/features/` but are not integrated into the application's entry point or organized into pages.

## Artifact Traceability

### spec.md
- **Affected user story**: All (US1, US2, US3, US4) - none are accessible to the user.
- **Affected requirements**: 
    - **FR-004**: Dashboard display.
    - **FR-001**: Group creation/management.
    - **Security**: Basic authentication requirement.
- **Gap identified**: The specification describes the features and the dashboard contents but does not explicitly define the application's navigational structure or the requirement for a Login/Signup user interface.

### plan.md
- **Affected sections**: Project Structure, Technical Context.
- **Impact**: The plan lacks a routing strategy (e.g., React Router) and does not account for an "Auth" feature in the `frontend/` layer.

### tasks.md
- **Affected tasks**: T018, T019, T026, T027, T032, T039, T040 (Orphaned features).
- **False completions**: These tasks are marked complete as the internal logic of the features is implemented, but they are not functional within the app context.
- **Missing tasks**:
    - [ ] Setup React Router and basic routing structure in `frontend/src/app/`
    - [ ] Create Auth feature (Login/Signup forms) in `frontend/src/features/auth/`
    - [ ] Create Page components (Dashboard, Login, Settings) in `frontend/src/pages/`
    - [ ] Integrate widgets and features into the Dashboard page
    - [ ] Implement Auth guarded routes

## Root Cause Analysis
The implementation followed a feature-first approach without defining the integration layer (pages and routing). While the API-side authentication was implemented, the frontend counterpart was missing from the plan and tasks. The tasks were marked complete upon finishing the individual feature components, ignoring the fact that they were not accessible to the user.

2. Run `/speckit.bugfix.verify` to confirm consistency across artifacts.
3. Resume `/speckit.implement` to apply the code fix (setup routing, create pages, and implement auth UI).
