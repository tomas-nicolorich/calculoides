### Fallow Gate
*~1,500 tokens/session saved*
- The pre-commit hook runs `fallow audit --base <upstream> --quiet --gate-marker pre-commit`. In a worktree with no upstream, the gate falls back to `main` and may over-report. Fix: `git branch --set-upstream-to origin/develop <branch>` before committing.
- Never use `--no-verify` to bypass the gate; fix reported issues or update `.fallowrc.json` to ignore false positives instead.

### Supabase / Prisma TLS
*~1,200 tokens/session saved*
- The recurring 'self-signed certificate in certificate chain' error on Vercel is caused by `sslmode=require` in `DATABASE_URL`. Prisma handles TLS separately via `DATABASE_CA_CERT`. The fix: remove `sslmode=require` from the URL, or switch the env var to `POSTGRES_PRISMA_URL` (which includes `?pgbouncer=true` for the pooler on port 6543). Do not add `rejectUnauthorized: false` — that disables TLS verification in production.

### File Paths
*~800 tokens/session saved*
- There is **no `/src` directory at repo root**. TypeScript source lives in `api/src/`, `frontend/src/`, and `shared/`. Never search `calculoides/src` — it does not exist and will always error.
- The Prisma schema is at `prisma/schema.prisma` (repo root, ~900 lines/36 KB). Grep for specific model names rather than reading the whole file.

### Worktrees
*~700 tokens/session saved*
- Worktrees live at `.claude/worktrees/<name>/`. Inside a worktree session `cd api` fails because CWD is already the worktree root. Set `ROOT=/home/tom/projects/calculoides/.claude/worktrees/<name>` and navigate with absolute paths: `cd "$ROOT/api"`.
- After entering a worktree, run `git rebase origin/develop && npm install --workspaces` before any work — the worktree starts from HEAD and may not be rebased or have dependencies installed.

### Test Commands
*~600 tokens/session saved*
- Run all tests from repo root: `npm test`. Workspace-specific: `npm test -w api` or `npm test -w frontend`. TypeScript check: `npm run typecheck` (all) or `npm run typecheck -w api`.
- API integration tests require Supabase env vars loaded via `api/vitest.config.ts`. Frontend tests need `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` configured in `frontend/vite.config.ts` or `.env.test` at repo root.
