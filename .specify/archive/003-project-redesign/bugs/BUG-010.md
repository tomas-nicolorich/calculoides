# Bug Report: Login Screen Redesign Spec Gap

**Status**: Patched
**Patched**: 2026-05-29
**Type**: Spec gap
**Severity**: High
**Feature**: 003-project-redesign
**Reported**: 2026-05-29

## Description
The application login screen (consisting of `LoginPage.tsx` and `LoginForm.tsx`) has not been updated with the new modern design. While the post-login pages (such as My Groups, Dashboard, and Savings Goal) have been updated to the "sleek, colorful, and subtle" card-based layout using Tailwind 4 CSS variables and Base UI, the Login Screen still uses older styles (like `bg-gray-100`). This results in a jarring and inconsistent user experience during the entry transition of the application.

## Artifact Traceability

### spec.md
- **Affected user story**: User Story 3 - Global Navigation & Settings (Priority: P2) / User Story 1 - Dashboard Overview (Priority: P1)
- **Affected requirements**: 
    - **FR-007**: System MUST provide a "My Groups" page, serving as the initial landing page after login...
    - **FR-010**: System MUST include a functional Sign Out option... (which redirects users back to the login screen).
- **Gap identified**: The login screen is the primary gateway to the application and the redirect target after signing out, but its redesign was completely omitted from the feature specification, resulting in an inconsistent visual scheme across user session lifecycles.

### plan.md
- **Affected sections**:
    - **Summary**: Mentions redesigning "comprehensive dashboard", "new Expenses page", "Savings Goal page", and "global hamburger menu", but misses the Login Screen redesign.
    - **Scale/Scope**: Omitted the login screen and form components from the list of target redesign components.
- **Impact**: The plan needs to be updated to include the login page and authentication form redesign under the visual redesign scope.

### tasks.md
- **Affected tasks**: None directly affected as the login redesign was never part of the original checklist.
- **False completions**: None.
- **Missing tasks**:
    - [ ] Create redesign test for the Login screen in `frontend/tests/pages/login.test.tsx`
    - [ ] Redesign `frontend/src/pages/LoginPage.tsx` using the new global Tailwind 4 color variables and aesthetic.
    - [ ] Redesign `frontend/src/features/auth/ui/LoginForm.tsx` using the custom `Card` primitive and modern inputs to match the new visual guidelines.

## Root Cause Analysis
During the design phase of the 003-project-redesign, the specification focused entirely on post-authentication features (Dashboard, Expenses, Transfers, Savings Goals, and Groups/Profile pages). The Login Page and Login Form were treated as out-of-scope or overlooked entirely, leading to a "Spec gap" where the application's entry page remains in the legacy style.

## Recommended Fix
1. Run `/speckit.bugfix.patch` to update `plan.md` and `tasks.md` to include the Login screen redesign.
2. Run `/speckit.bugfix.verify` to confirm consistency.
3. Resume `/speckit.implement` to apply the visual updates to the login page and form features.
