**Type**: Implementation drift

## Description
When clicking on the "Savings Goal" button on the main Dashboard, the user is redirected to the "My Groups" page instead of the expected "Savings Goal" page (calculator).

## Artifact Traceability

### spec.md
- **Affected user story**: User Story 1 - Dashboard Overview (Priority: P1)
- **Affected requirements**: 
  - **Acceptance Scenario 3**: "Given the user is on the dashboard, When they click the Savings Goal button, Then they are navigated to the Savings Goal page."
  - **FR-002**: "System MUST provide a prominent button on the dashboard that navigates to the Savings Goal page."
- **Gap identified**: None in spec; the specification correctly defines the navigation requirement. This is an implementation error where the destination route or link configuration is incorrect.

### plan.md
- **Affected sections**: Project Structure (Source Code), Complexity Tracking (eventually)
- **Impact**: The routing logic in the frontend needs to be corrected to point to the valid "Savings Goal" route.

### tasks.md

- **Missing tasks**: A verification task/test case specifically for this navigation is needed if not already present in T009b.

## Root Cause Analysis
Implementation drift. While the code in `DashboardPage.tsx` uses a `<Link to="/savings">`, it is likely that:
1. The route `/savings` is incorrectly mapped to the Groups page in `App.tsx` or the router configuration.
2. Or, there is a middleware/guard issue causing a redirect to `/groups` (the landing page) when accessing `/savings`.
3. Or, the path in the Link component was meant to be something else (e.g., `/calculator`) but was implemented as `/savings` which might be aliased or defaulted to the landing page.
