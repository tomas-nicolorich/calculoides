# Bug Report: Stacked Bar Chart Color Merging and Missing Legend in Income Overview

**Type**: Implementation drift
**Severity**: Medium
**Feature**: 003-project-redesign
**Reported**: 2026-05-29
**Status**: Patched
**Patched**: 2026-05-29

## Description
In the Income Overview widget, the horizontal stacked bar chart does not clearly represent the group's income distribution when there are more than two members.

1. **Color Merging**: The chart relies on a conditional statement that maps `index === 0` to `bg-brand-income`, `index === 1` to `bg-brand-balance`, and any index `>= 2` to `bg-brand-category` (purple). Consequently, for groups with 3 or more members, all members from the third member onwards are colored with the exact same purple. Because these segments are adjacent to each other with no dividers or borders, they merge visually into a single solid purple segment. This makes it look like there is one large segment representing multiple members, as shown in `@docs/124309.png`.
2. **Missing Legend**: There is no color key or indicator next to each member's name in the listing below the bar. Users cannot identify which color segment on the chart corresponds to which member without hovering to see the browser tooltip.

## Root Cause Analysis
1. **Fallback Conditional Logic**: The implementation uses a simplified three-way conditional expression `index === 0 ? "bg-brand-income" : index === 1 ? "bg-brand-balance" : "bg-brand-category"` to color individual bar segments. For groups with three or more members, index 2, 3, etc. are all styled with `bg-brand-category`, causing adjacent segments to merge into one continuous block.
2. **Omission of Legend/Key Indicator**: The UI layout for the member breakdown has no visual color indicator linking the list row to the bar segment. This violates basic data visualization best practices, making the chart unusable on touch screens or without cursor hovering.
