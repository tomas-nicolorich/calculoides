## Description
A TypeError occurs when navigating to /groups. The application crashes with Uncaught TypeError: Cannot read properties of undefined (reading 'toLowerCase') at GroupsPage.tsx:51:84. This happens within an Array.map call, suggesting that either the groups array contains an undefined element or a property being accessed on a group object for comparison/filtering is undefined.

## Root Cause Analysis
The crash is likely caused by an attempt to access a property (e.g., group.name or group.id) on an undefined item in the groups array, or calling .toLowerCase() on a property that is undefined for at least one group. This could occur if the API returns a list with a null/undefined entry or if a group is missing a field that the UI expects to be present for filtering/sorting.
