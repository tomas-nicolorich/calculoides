# Bug Report: Savings Goals Dark Mode Card Background and Status Contrasts

**Status**: Patched
**Patched**: 2026-05-29
**Type**: Implementation drift
**Severity**: High
**Feature**: 003-project-redesign
**Reported**: 2026-05-29

## Description
When Dark Mode is active, the Savings Goals page has visual and contrast issues. Specifically, some card backgrounds remain white or light-colored (the success state background `bg-emerald-50/30` makes the card render as an off-white box in dark theme). Additionally, several status badges and informational texts, such as the "On Track" badge (`bg-emerald-100 text-emerald-700`) and the projected date text (`text-emerald-600`), lack dark mode equivalents, resulting in poor contrast and unreadable text against dark backdrops.

## Root Cause Analysis
The root cause is implementation drift where state-specific container colors and contextual text classes were hardcoded for light mode without dark theme overrides:
1. **Success Card State**: The success state background `bg-emerald-50/30` overrides the card's theme background (`bg-card` which translates to `bg-slate-900` in dark mode). Because `bg-emerald-50` is near-white, it renders the card as a bright white-green card even when dark mode is enabled.
2. **Missing Theme Variants on Status Badges**: The "On Track" status badge is styled with static classes (`bg-emerald-100 text-emerald-700 border-emerald-200`) and lacks `dark:` utility variants, causing legibility issues and ruining design immersion in dark mode.
3. **Low Contrast Contextual Text**: Text elements like the projected date use `text-emerald-600`, which is too dark and has insufficient contrast against `bg-slate-900/50` in dark mode.
