# Bug Report: Import Resolution Failure for Base UI Dialog

**Status**: Patched
**Patched**: 2026-06-02
**Type**: Dependency issue
**Severity**: Critical
**Feature**: 003-project-redesign
**Reported**: 2026-06-02

## Description
Vite fails to resolve the import `\@base-ui-components/react/dialog` in `src/shared/ui/Dialog.tsx`. This causes an internal server error that blocks the frontend development server. 

The error message indicates that the module `\@base-ui-components/react/dialog` cannot be found, despite it being intended for use as the primitive for the custom Dialog component.

## Artifact Traceability

### spec.md
- **Affected user story**: US1 - Dashboard Overview (specifically related to custom UI dialogs)
- **Affected requirements**: SC-006 (Custom UI components for user feedback and confirmations)
- **Gap identified**: None in the spec itself, but the implementation fails to meet the success criterion due to the broken dependency.

### plan.md
- **Affected sections**: Technical Context (Primary Dependencies), Complexity Tracking (BUG-008)
- **Impact**: The plan lists `@base-ui-components/react` as a primary dependency in the summary, but the project is actually using `@base-ui/react`. This inconsistency led to the incorrect import path in the implementation.

### tasks.md
- **Affected tasks**: 
    - T039: Create redesign test for Savings Goal page (Indirectly affected)
    - T040: Replace browser confirm() with custom Dialog component (Directly blocked)
- **False completions**: T039 and T040 are marked as complete but are functionally broken due to the import error in their supporting component (`Dialog.tsx`).
- **Missing tasks**: None, but T039 and T040 need to be revisited after fixing the dependency.

## Root Cause Analysis
The project's `frontend/package.json` contains `@base-ui/react`, but the code in `src/shared/ui/Dialog.tsx` was written using the (likely outdated or incorrect) package name `@base-ui-components/react/dialog`. This is a classic implementation drift caused by a mismatch between the planned dependency name and the actual installed package.

## Recommended Fix
1. Run `/speckit.bugfix.patch` to update `plan.md` and `tasks.md` to consistently reference `@base-ui/react`.
2. Run `/speckit.bugfix.verify` to confirm consistency across all spec artifacts.
3. Resume `/speckit.implement` to fix the import in `frontend/src/shared/ui/Dialog.tsx` and any other affected files.
