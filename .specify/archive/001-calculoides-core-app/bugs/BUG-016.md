# Bug Report: Missing database type "calculoides.invitation_status"

**Type**: Implementation drift
**Severity**: High
**Feature**: 001-calculoides-core-app
**Reported**: 2026-05-15

## Description
When attempting to invite a user, the application fails with a database error:
`prisma:error type "calculoides.invitation_status" does not exist`
`Auth Middleware Error: DriverAdapterError: type "calculoides.invitation_status" does not exist`

This occurs because the `Invitation` model in `prisma/schema.prisma` uses a custom `InvitationStatus` enum which maps to the Postgres type `calculoides.invitation_status`. This type either hasn't been created in the database or the migration was not successfully applied to the target environment.

## Root Cause Analysis
1. **Implementation Drift**: The code uses a Postgres Enum (`InvitationStatus`) while the `data-model.md` specifies a `String`.
2. **Migration Failure/Omission**: The custom Postgres type `invitation_status` was not created in the `calculoides` schema of the database, or the Prisma migration was not properly applied.
