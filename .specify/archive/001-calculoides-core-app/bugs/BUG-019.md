# Bug Report: Missing Member Shares and Spending in Category View

**Type**: Implementation drift
**Severity**: Medium
**Status**: Patched
**Patched**: 2026-05-15
**Feature**: 001-calculoides-core-app
**Reported**: 2026-05-15

## Description
When viewing budget categories in the application, the UI fails to display the members associated with the category, their respective proportional shares (in currency/percentage), and their individual current spending against those shares. Users can only see the group total, which lacks the granular detail required for proportional sharing.

## Artifact Traceability

### spec.md
- **Affected user story**: US2 — Budgeting & Spending
- **Affected requirements**: 
    - "Members can see their individual share, the other member's shares and the group total for each category." (Budget categories description)
    - "The application tracks how much of each category's monthly budget has been spent and shows the remaining balance." (Expense tracking description)
    - **FR-004**: "System MUST display a dashboard showing ... remaining balance per user ... and category status."
- **Gap identified**: While the requirements mention tracking and showing these values, the explicit layout for the category card/detail wasn't detailed enough to ensure per-member spending was prioritized in the UI implementation.

### plan.md
- **Affected sections**: Technical Context, Summary.
- **Impact**: UI components in the `budget` feature need to be updated to render member-specific data. `BudgetService` might need to be verified to ensure it provides a per-member breakdown of `spent` and `remaining` amounts.

### tasks.md
- **Affected tasks**: 
    - **T027**: "Create Category list and Expense entry UI in frontend/src/features/budget/"
    - **T026**: "Implement Dashboard Summary widget in frontend/src/widgets/dashboard/"
    - **T023**: "Implement BudgetService for balance tracking in api/src/services/budget.ts"
- **False completions**: T027, T026, and T023 are currently marked as complete but clearly fail to provide the full visibility required by the spec.
- **Missing tasks**: 
    - [US2] Update `BudgetService` to return per-member spending and quota breakdown for each category.
    - [US2] Enhance Category card UI to display a list of members with their share, spent amount, and remaining balance.

## Root Cause Analysis
The implementation focused on group-level category totals and individual dashboard summaries but missed the requirement to show the breakdown of "who owes what and has spent what" *within* the specific category view. This is an implementation drift where the code fulfilled the basic functionality but skipped the comparative visibility mandated by the spec.

1. Run `/speckit.bugfix.patch` to update `spec.md` and `plan.md` to explicitly define the expected UI breakdown for categories.
2. Run `/speckit.bugfix.verify` to confirm consistency.
3. Resume `/speckit.implement` to:

    - Update the Category List/Card components to render this breakdown.
