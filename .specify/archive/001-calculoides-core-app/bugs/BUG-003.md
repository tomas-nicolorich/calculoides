# Bug Report: API Proxy Failure in Dashboard

**Type**: Dependency issue
**Severity**: High
**Feature**: 001-calculoides-core-app
**Reported**: 2026-05-14

## Description
After a successful login, the `DashboardPage` fails to load group data. The console shows a `SyntaxError: Unexpected token '<'` when attempting to parse the JSON response from `apiClient.groups.list()`. This indicates that the request is receiving an HTML response (likely the Vite `index.html`) instead of the expected JSON data from the API.

## Root Cause Analysis
The bug is caused by an incomplete environment configuration in `frontend/vite.config.ts`. Although `envDir` was configured to point to the root `.env` file, standard `process.env` access does not work within the Vite config file itself during the build/dev process. As a result, the `proxy` configuration remains `undefined`, and requests to `/api/*` are captured by Vite's fallback mechanism, which returns the SPA's `index.html` (starting with `<!DOCTYPE html>`), leading to the JSON parsing error in the frontend.
