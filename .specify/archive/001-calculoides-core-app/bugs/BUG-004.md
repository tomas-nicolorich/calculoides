# Bug Report: Vite Proxy ECONNREFUSED for /api/groups

**Type**: Dependency issue
**Severity**: High
**Feature**: 001-calculoides-core-app
**Reported**: 2026-05-14

## Description
The frontend dev server (Vite) fails to proxy requests to `/api/*`, resulting in an `AggregateError [ECONNREFUSED]` on port 3001 in the terminal console. This occurs when running the project via the standard `npm run dev` command. The error indicates that the proxy is correctly configured to target `http://localhost:3001`, but the backend service is either not running or listening on a different port.

```text
frontend:dev: 12:07:25 [vite] http proxy error: /api/groups
frontend:dev: AggregateError [ECONNREFUSED]:
frontend:dev: at internalConnectMultiple (node:net:1134:18)
frontend:dev: at afterConnectMultiple (node:net:1715:7)
```

## Root Cause Analysis
The project has two backend execution paths: 
1. `npm run dev` -> `vercel dev` (defaults to port **3000**).
2. `npm run dev:local` -> `node src/server.ts` (defaults to port **3001**).

The Vite proxy in `frontend/vite.config.ts` is hardcoded to target `http://localhost:3001`. When a developer uses the standard `npm run dev` command, the Vercel server starts on port 3000, but the frontend attempts to proxy `/api` requests to 3001, resulting in `ECONNREFUSED`.

2. Run `/speckit.bugfix.verify` to confirm consistency.
3. Resume `/speckit.implement` to:
    - Update `api/package.json` to force `vercel dev` to listen on port 3001: `"start:api": "vercel dev --listen 3001"`.
    - Verify that both `npm run dev` and `npm run dev:local` now work correctly with the frontend proxy.
