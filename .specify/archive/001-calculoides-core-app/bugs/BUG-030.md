# Bug Report: Missing CategoryExpenseList Import in DashboardPage

**Type**: Implementation drift
**Severity**: Medium
**Feature**: 001-calculoides-core-app
**Reported**: 2026-05-29
**Status**: Patched
**Patched**: 2026-05-29

## Description
When clicking on a budget category in the Dashboard, the application fails with a `ReferenceError: CategoryExpenseList is not defined`. This occurs because the `CategoryExpenseList` component is used in `renderTabContent` (DashboardPage.tsx:145) but is not imported at the top of the file.

```text
Uncaught ReferenceError: CategoryExpenseList is not defined 
at renderTabContent (DashboardPage.tsx:145:16) 
at DashboardPage (DashboardPage.tsx:296:11)
```

## Root Cause Analysis
Implementation drift. The component `CategoryExpenseList.tsx` was created as part of the fix for BUG-025, and code was added to `DashboardPage.tsx` to use it, but the necessary `import` statement was omitted from `DashboardPage.tsx`.
